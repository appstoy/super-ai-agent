# ADR-0003：工具采用能力声明和默认拒绝

- 状态：Accepted
- 日期：2026-11-07

## 背景

事件驱动 Agent 会接触不可信文本，且端侧环境可能包含代码、私有文件和凭据。单靠提示词约束不能形成安全边界。

## 候选方案

1. 工具能力声明、策略检查、资源限制、审批和审计。
2. 仅靠系统提示词告诉模型哪些命令安全。
3. 所有工具放进完全隔离的云沙箱。

## 决策

采用能力声明加程序策略，默认拒绝高风险操作。端侧 daemon 只接受短期签名、白名单能力和结构化参数；密钥通过代理使用，不进入模型上下文。云沙箱作为后续执行适配器，不作为 MVP 的唯一安全假设。

## 代价与影响

- 工具开发需要声明权限和资源上限，使用前要处理审批状态。
- 用户体验会多出确认步骤，但可避免提示词注入直接扩大权限。
- 安全策略必须有测试、审计和版本号，策略变更应可追踪。
