# ADR-0011：API 进程内恢复消费者

## 状态

已接受（Phase 7）

## 决策

- `super-agent serve` 启动一个轻量 `DurableOutboxWorker` 线程，自动处理服务启动前已经提交的 Outbox 和过期 Run。
- API 线程池和恢复消费者共享数据库租约；claim/lease 保证重复运行不会重复执行同一事件。
- 外部模型凭证缺失或暂时不可用时，恢复线程保留并周期性重试，不终止 HTTP 服务。
- 生产环境仍可运行独立 `super-agent worker`，多个消费者通过数据库租约协调。

## 后果

- 单进程快速启动具备重启后恢复能力，不需要用户手动再执行一次任务。
- 同一个进程会有 API 线程池和恢复线程，需要通过数据库 lease 控制并发。
