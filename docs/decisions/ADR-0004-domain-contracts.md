# ADR-0004：领域接口与适配器隔离外部依赖

- 状态：Accepted
- 日期：2026-11-07

## 背景

项目需要支持多个模型供应商、渠道、执行环境和消息总线。直接在 Router/Worker 中调用 SDK 会造成供应商锁定和难以测试。

## 候选方案

1. 领域层定义 ModelGateway、ChannelAdapter、Tool、EventBus 等端口，外部实现放在 adapters。
2. 选择一个供应商 SDK 并让业务代码直接依赖。
3. 通过通用工作流框架隐藏全部领域对象。

## 决策

采用端口与适配器。公共输入输出使用项目自己的 Pydantic/领域类型，供应商错误映射到统一错误分类；Mock 实现用于离线测试。

## 代价与影响

- 需要维护接口、适配器和契约测试。
- 新供应商接入成本较低，但最先进的供应商特性可能需要扩展公共能力模型。
- 框架只作为实现细节，不能取代任务和权限领域模型。
