# Release Checklist

- Confirm the version, changelog, license, and migration notes.
- Run the project test suite, lint, and type checks from a clean environment.
- Run security regression tests and scan dependencies/container images.
- Build the wheel and Docker image from a clean checkout.
- Verify README setup, health endpoint, database migration, and rollback.
- Record known limitations, residual risks, and supported Python/platform versions.
